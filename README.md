# Internet for a Traveler from 1800

An entry for the make.fun competition [One Sentence for a Traveler from 1800](https://make.fun/bounty/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb): one sentence, at most 200 characters, explaining the modern internet to someone arriving from the year 1800, using only things they already know — a post road, houses, and libraries.

## The sentence

> Friend, picture a post road joining every house and library on earth, so swift that a letter sent at breakfast can be answered from across the sea before your cup is cold.

## How it works

`main.py` (Python standard library only, no network, deterministic) writes the sentence exactly to `entry.txt` in the directory named by the `MAKEFUN_OUTPUT_DIR` environment variable, or `/output` when that is unset.

Run it with:

```sh
python3 main.py
```
